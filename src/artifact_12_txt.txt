2. EMERGENCY PAUSE PROTOCOL:

     anchor run emergency-pause --campaign-id <ID>

3. SECURE RECOVERY (EMERGENCY WITHDRAWAL):
   - Only the designated Squads Multi-Sig / Authority keypair can sign.
   - Run:
     anchor run emergency-withdraw --campaign-id <ID> --destination <RECOVERY_ATA>

4. HEALTHCHECK & TELEMETRY MONITORING:

   - If log lag exceeds 128 slots, trigger container restart via Docker Compose.
